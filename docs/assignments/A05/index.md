# A5 Bracket Design

# Problem
In this project we were tasked to design a bracket to hold an applied force from a hangin strap. We could choose from 3 materials including aluminum 6061 T6, Steel ASTM A36, or Ti-6Al-V4. We were give a basic bracket design for which we were instructed to break up into 5 features and run stress and stiffness analysis to determine optimal dimensions.

# Stress Analysis
For each of the 5 features, I created a free body diagram and listed the assumptions, known, and unknown values. Known measurements came from the insertion diagram and from measurements derived from previous features. Where required I assigned arbitrary measurements of 1 inch. Once this was accomplished I plugged in the applicable stress formula from the Machinery's Handbook and plugged in my known values.

# Stiffness Analysis
I used the same set up for each feature as used in stress analysis, but included a known value for maximum deflection of .005 in per instructions. I used this known value to find the same unknown dimensions as in stress analysis but using deflection formulas found in the machinery's handbook instead.
