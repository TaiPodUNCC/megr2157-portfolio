# A5 Bracket Design

# Problem
In this project we were tasked to design a bracket to hold an applied force from a hangin strap. We could choose from 3 materials including aluminum 6061 T6, Steel ASTM A36, or Ti-6Al-V4. We were give a basic bracket design for which we were instructed to break up into 5 features and run stress and stiffness analysis to determine optimal dimensions.
